# Curated agent completion-sound sets, read by fetch-completion-sounds.sh.
#
# Format, one clip per line:
#   <folder>|<wiki filename>|<quote>|<wiki>
#
# folder        Destination under ~/sounds/. Matches the existing naming scheme
#               (sc1-ghost, sc2-ghost, wc2-death-knight).
# wiki filename Exact File: name on the wiki. The download URL is derived from
#               its MD5, so the name must match the wiki exactly.
# quote         The spoken line, for reference when picking favorites.
# wiki          Optional image-path segment of the source wiki. Defaults to
#               "starcraft". Note this is the wiki's internal name, not its
#               subdomain: warcraft.fandom.com serves images under "wowpedia".
#
# Blank lines and lines starting with # are ignored. Add a set by appending
# lines; no code change is needed.
#
# Prefer short lines (1-3s) so a clip does not overlap the next agent turn.
